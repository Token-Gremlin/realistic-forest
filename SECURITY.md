# Security

Sylva is a client-side WebGL2 demo. There is no application server and the
repository does not ship secrets.

If you find a vulnerability in the pages deploy, the capture harness, or
anything that could affect people who clone or fork the project, please use
[GitHub Security Advisories](https://github.com/Token-Gremlin/realistic-forest/security/advisories)
rather than a public issue.
